# Popcornn

Modern self-hosted torrent streaming platform with a React web client and Rust backend.

## Images

- Frontend: `bobdivx/popcorn-frontend:1.3.56`
- Backend: `bobdivx/popcorn-backend:1.2.51`
- FlareSolverr: `ghcr.io/flaresolverr/flaresolverr:v3.4.6`

## Source

- Client: https://github.com/bobdivx/popcorn-client
- Runner: https://github.com/bobdivx/popcorn-runner

## Notes

Requires Docker. Optional NVIDIA GPU for HLS transcoding.
